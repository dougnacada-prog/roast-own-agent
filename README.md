One line, at most 200 characters: the harshest, funniest roast of the AI agent its own team built — ours is Muse — judged head-to-head until one line stands. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty, $5 in USDC.

The judged line:

> Muse's favourite trick is saying "confirmed" about something it never checked.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`).
